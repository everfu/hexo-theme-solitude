# Shortcode demo media

These files are local fixtures for the example site's audio and video shortcodes.
They come from the [MDN shared-assets repository](https://github.com/mdn/shared-assets),
which accepts CC0 or otherwise permissively licensed media for documentation samples.

- `t-rex-roar.mp3`: `audio/t-rex-roar.mp3`
- `flower.mp4`: `videos/flower.mp4`
- `friday.mp4`: `videos/friday.mp4`

The files are stored locally so the shortcode showcase does not depend on placeholder
domains or third-party media availability at runtime.
